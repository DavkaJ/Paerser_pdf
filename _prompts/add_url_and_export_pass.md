# Добавить url в метаданные + выгрузить PASS-файлы отдельно

Выполнять ПОСЛЕ уборки git (_prompts/commit_and_push.md). Схема ссылки подтверждена вживую в браузере: `https://cr.minzdrav.gov.ru/view-cr/{id}` (напр. view-cr/1052_1, view-cr/9_3). Реестр ссылки не содержит — строим из поля `id`.

```
Две задачи: (1) добавить поле url в метаданные КР; (2) отложить PASS-файлы в отдельную папку
для передачи коллеге. Парсинг/структуру НЕ трогать — только сборка метаданных и копирование.

=== ЗАДАЧА 1: поле url в метаданных ===
Файл crparser/profiles/clinical.py — сборка словаря metadata (там, где формируются id/developer/
approval_status и т.п.). Добавить поле:
    meta["url"] = f"https://cr.minzdrav.gov.ru/view-cr/{id}" if id else None
где id — то же значение, что уже кладётся в meta["id"] (стем имени файла вида «9_3», «1052_1»).
- url отдавать ТОЛЬКО при непустом валидном id; иначе None (не строить битую ссылку).
- Разместить поле рядом с id в выходном словаре (после id/или в конце metadata — на твой выбор,
  но стабильно для всех файлов).

ГРАНИЦЫ: править только сборку metadata в clinical.py. НЕ трогать: разделы, таблицы, content-start,
детекторы порчи, validate.py, tables.py. Без хардкода URL под конкретные файлы. Схему URL брать
ровно «https://cr.minzdrav.gov.ru/view-cr/{id}».

=== ЗАДАЧА 2: выгрузка PASS ===
После добавления url — ПОЛНЫЙ регресс (пересобрать outout/ и _corpus/report.json, интеграл-чек JSON).
Затем:
1. Создать папку outout_pass/ (она попадает под .gitignore `out*/` — в git не коммитить).
   Если папка есть — очистить перед копированием.
2. Скопировать в outout_pass/ каждый файл outout/<name>.json, у которого в _corpus/report.json
   status == "PASS". Копировать именно свежие файлы из outout/ (с уже добавленным url).
3. Напечатать: сколько файлов скопировано (ожидается = число PASS в report.json).
4. (опционально) Заархивировать outout_pass/ в outout_pass.zip для отправки.

=== ТЕСТЫ-ПИНЫ ===
- metadata.url в outout/КР9_3.json == "https://cr.minzdrav.gov.ru/view-cr/9_3".
- metadata.url в outout/КР1000_1.json == "https://cr.minzdrav.gov.ru/view-cr/1000_1".
- Если в корпусе есть файл с пустым/нестандартным id — у него metadata.url == null (не битая ссылка).
- Регрессия: добавление url НЕ меняет статусы — число PASS/FAIL/REVIEW в report.json прежнее
  (PASS = как было, ~596); никакие другие поля метаданны не изменились; все JSON валидны.
- В outout_pass/ лежит ровно число PASS файлов, все — со статусом PASS, у каждого есть metadata.url.

=== РЕГЛАМЕНТ ===
- Коммитить ТОЛЬКО правку clinical.py (поле url). Папку outout_pass/ и zip НЕ коммитить
  (она под out*/ в .gitignore).
- Сообщение коммита — по существу, без упоминания Claude/AI/ассистента и без Co-Authored-By.
- Пуш ветки.
```
