### Подпроблема 1: приложенческая нумерация не распознаётся вообще
_RE_TABLE_CAPTION (tables.py:37-39):
  r"^\s*Таблица\s+(П?[\dЗз]+(?:[.,][\dЗз]+)*(?:\s+[\dЗз]\b)*)\.?\s*(.*)$"
После «П» допускаются только цифры. Не матчатся:
- «Таблица ПА3-1» — буква после «П» и дефис. КР37_2: PDF строки 3094 (ПА3-1), 3119 (ПА3-2),
  3151 (ПА3-3), 3394 (ПГ-2), 3500 (ПГ-3). В outout/КР37_2.json все пять отсутствуют как
  captions — текст подписей утёк в text приложений А3/Г, таблицы отданы с caption null.
- «Таблица 1/А2» (КР37_2, PDF 2898-2981, пять штук) матчится СЛУЧАЙНО: группа номера
  обрезается на слэше, number = «1» вместо «1/А2», хвост «/А2» уезжает в caption.

Расширь формат номера в _RE_TABLE_CAPTION (и согласованно _norm_table_number) до закрытого
множества форм:
1. существующие N, N.N (запятая как точка), ПN (П1, ПЗ→П3 OCR) — не менять;
2. приложенческий буквенный префикс: П + 1-2 ЗАГЛАВНЫЕ кириллические буквы + опц. цифра +
   дефис + число: обобщённо П[А-ЯЁ]{1,2}\d?-N; цифра после дефиса ОБЯЗАТЕЛЬНА
   («Таблица ПА» без числа матчиться не должна);
3. слэш-суффикс приложения: N/Аk («1/А2») — номер захватывается ЦЕЛИКОМ, number = «1/А2»…
Не расширяй сверх этого: произвольные слова после «Таблица», латиница, голые буквы без цифр —
не матчить. Разрядку в новой форме номера обрабатывать как текущий _norm_table_number.

### Правильное поведение
- «Таблица ПА3-1/2/3», «Таблица ПГ-2/3» распознаются (number+caption); текст подписи не болтается.
- «Таблица N/Аk» надёжна целиком, number — полная форма («1/А2»…).
- Обычные «Таблица N» не теряются при слитом bbox и разрыве страницы (КР256_2 таб.1 и 5; КР614_3 таб.5).
- Законный null остаётся null: таблицы без подписи в PDF (КР9_3 «Критерии качества», КР717_2,
  продолжения многостраничных таблиц) НЕ получают выдуманную/чужую подпись.

### ГРАНИЦЫ (жёстко)
- Править ТОЛЬКО детектор/привязку подписей в tables.py (_RE_TABLE_CAPTION, _norm_table_number,

  под caption-якорь) + опциональный пункт validate.py ниже.
- НЕ трогать структуру разделов, content-start, детекторы порчи, whitespace-fallback в его текущей

- НЕ откатывать и не ломать незакоммиченный фикс разрядки; его пины остаются зелёными.
- НЕ приклеивать подпись к чужой таблице; при сомнении null лучше мусора. Без хардкода.
