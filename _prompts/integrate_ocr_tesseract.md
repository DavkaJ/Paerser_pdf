# Интеграция OCR-восстановления через Tesseract (гибрид + полный режим)

Точки интеграции найдены в коде: pdf_reader.py `PdfReader.read()` (доступ к тексту+bbox через `page.get_text("dict")`, живой `self._doc` для рендера; строки ~124-131 — глифовая порча намеренно не чинится); textnorm.py — детекторы для переиспользования (`_is_section_sign_glyph_token`, `section_sign_glyph_tokens`, `pseudo_ascii_glyph_tokens`, `_RE_MIXED`, `looks_glyph_corrupted`); parser.py `DocumentParser.parse` — ветка полного OCR при пустом тексте / pseudo_ascii. Смок-тест подтверждён (pdftoppm -r 300 + tesseract rus+eng восстанавливает HBsAg/Hepatitis/anti-HCV). В песочнице только `eng` — в рабочем окружении нужен `rus`.

---

```
Задача: встроить OCR-восстановление битого текстового слоя в парсер КР (X:\parser),
через Tesseract. Два режима — ГИБРИД и ПОЛНЫЙ OCR. Реализация ИЗОЛИРОВАННАЯ:
чистые файлы идут прежним путём без OCR, без замедления и без изменения вывода.

═══ 1. ЦЕЛЬ И ДВА РЕЖИМА ═══
ГИБРИД (основной, для §-класса; эталон КР1_4): кириллица в слое ЧИСТАЯ, битая только
латиница (HBsAg→НВзА§, BCLC→ВСЬС, IgM/IgG→1§М/1§С, Child-Pugh→Ри§Ь, anti-HCV,
Hepatitis B/C virus). Основной текст извлекается как сейчас. Битые ТОКЕНЫ/СТРОКИ
локализуются, их bbox рендерится в растр, Tesseract `rus+eng`, из результата берётся
ВОССТАНОВЛЕННАЯ ЛАТИНИЦА и подставляется на места битых токенов. OCR-ить СТРОКУ/область,
НЕ одиночный глиф. Кириллица и структура сохраняются.
ПОЛНЫЙ OCR (для сканов SKIPPED_SCAN и тотальной порчи КР627_3/КР898_1, где годного
текста нет): рендер всех страниц, Tesseract `rus+eng` на страницу, из текста собрать
документ (та же JSON-схема, непустые sections).

═══ 2. ТОЧКИ ИНТЕГРАЦИИ И АРХИТЕКТУРА ═══
НОВЫЙ модуль crparser/engine/ocr.py (весь OCR-код изолирован здесь):
  class OcrRecoverer: hybrid_recover(doc, pages) -> изменённые Line.text; full_ocr(doc)
  -> страницы/строки из полного OCR.
  detect-часть переиспользует ТОЛЬКО существующие детекторы textnorm (не дублировать):
  §-класс — _is_section_sign_glyph_token + _RE_MIXED, порог документа
  section_sign_glyph_tokens; тотальная порча — pseudo_ascii_glyph_tokens;
  латиница→кириллица — glyph_suspect_count/looks_glyph_corrupted.
  render: fitz page.get_pixmap(matrix=fitz.Matrix(dpi/72,dpi/72)), DPI>=300, клип по
  bbox строки (+паддинг). tesseract: pytesseract ИЛИ subprocess; `-l rus+eng`, `--psm 7`
  для строки, `--psm 6` для блока. Путь к бинарю и TESSDATA_PREFIX из env, без хардкода.
ВЫЗОВ:
  ГИБРИД — в pdf_reader.py PdfReader.read(), пока self._doc открыт, после сборки строк,
  до возврата pages; хук у места, где глифовая порча детектируется и не чинится
  (~строки 124-131). Включать ТОЛЬКО при срабатывании плотностного §-порога по документу.
  Менять ТОЛЬКО Line.text битых строк; bbox/size/bold/структуру не трогать.
  ПОЛНЫЙ — в parser.py DocumentParser.parse, ветка после reader.read(), где
  full_text.strip() пуст ИЛИ pseudo_ascii_tokens>0. Собрать документ из полного OCR до
  close() reader.
ВЫБОР КАНДИДАТОВ (без хардкода имён): внутри парсера — по плотностным детекторам textnorm;
  на уровне батча (batch_report.py) — по классу из scan_candidates.csv (SKIPPED_SCAN
  сейчас исключается — для полного OCR включить отдельной веткой).

═══ 3. ЗАВИСИМОСТИ И УСТАНОВКА ═══
  Tesseract (бинарь) + traineddata `rus` И `eng`. В песочнице есть только `eng` — в
  рабочем окружении нужен tesseract-ocr-rus. Windows: путь к tesseract.exe и
  TESSDATA_PREFIX через env/конфиг, без хардкода. Python: pytesseract или subprocess.
  Рендер — PyMuPDF get_pixmap (уже установлен); fallback pdftoppm допустим. DPI>=300.
  Смок-тест-ориентир: pdftoppm -r 300 + tesseract `-l rus+eng` восстанавливает HBsAg,
  Hepatitis B/C virus, IgG, anti-HCV с битой страницы.

═══ 4. РЕАЛИЗАЦИЯ ГИБРИДА (пошагово) ═══
  1) Детект битых токенов: _is_section_sign_glyph_token + _RE_MIXED; документ-кандидат по
     section_sign_glyph_tokens (плотностной порог).
  2) Для каждой битой строки взять bbox (Line.bbox / span bbox).
  3) Рендер области при DPI>=300 (get_pixmap clip по bbox + паддинг).
  4) tesseract `-l rus+eng --psm 7` (строка) / `--psm 6` (блок).
  5) Из OCR извлечь ЛАТИНСКИЕ фрагменты (кириллицу из OCR не тащить — она в слое чистая).
  6) Подставить восстановленную латиницу на позиции битых токенов в Line.text, «§» убрать.
  ПОЛНЫЙ: рендер всех страниц → tesseract `-l rus+eng --psm 6` → в тот же конвейер
  (Segmenter/Stats) для непустых sections в штатной схеме.

═══ 5. ЯВНЫЕ ГРАНИЦЫ ═══
  - OCR активируется ТОЛЬКО для кандидатов (порча по детектору / скан по классу). Чистые
    файлы — прежним путём: без OCR/рендера/замедления, вывод байт-в-байт прежний.
  - НЕ трогать структурную логику разделов/таблиц/сегментации для чистых файлов.
  - Выход — та же JSON-схема; новых обязательных полей в схему чистых не добавлять.
  - Без хардкода имён файлов — только детекторы/класс.
  - OCR-путь изолирован в ocr.py; падение Tesseract (нет бинаря/нет rus/ошибка) НЕ
    должно ронять основной парс — graceful fallback: предупреждение в лог, вернуть
    исходный текст, файл парсится как прежде.

═══ 6. ТЕСТЫ-ПИНЫ ═══
  ГИБРИД — КР1_4: HBsAg, Hepatitis B/C virus, anti-HCV, IgG/IgM восстановлены; «§» ушёл;
    кириллица и дерево сохранены; §-детектор в validate.py = 0; файл становится PASS.
  ПОЛНЫЙ — один скан из scan_candidates.csv + КР627_3, КР898_1: полный OCR даёт НЕПУСТЫЕ
    sections.
  РЕГРЕССИЯ — КР1000_1, КР802_1, КР845_1: НЕ проходят через OCR, вывод не меняется
    (сравнить JSON), время парса чистых НЕ растёт.

═══ 7. РЕГЛАМЕНТ ═══
  - Прогон на подвыборке кандидатов (эталоны порчи + сканы) и на регресс-наборе чистых.
  - Пере-валидация validate.py: у восстановленных §-детектор = 0, статус PASS.
  - Интеграл-чек целостности всех outout/*.json.
  - Коммит ТОЛЬКО при отсутствии регресса на чистых (их JSON и время не изменились).
  - Сообщение коммита — без упоминания Claude/AI, без Co-Authored-By.
```
