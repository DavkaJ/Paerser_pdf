# PUA-нормализация символьных шрифтов → Unicode (Adobe Symbol)

Детерминированно, без моделей. Символьные шрифты PDF кладут глифы в Private Use Area
(U+E000–U+F8FF) при битом/отсутствующем ToUnicode; правильный Unicode — глиф Symbol для кода
(F000+код). Char-map длину сохраняет (все Symbol-значения — 1 символ) → stats не плывут,
OCR-дрейфа нет, не-PUA контент байт-в-байт цел.

## Итог
- найдено: **36 974 вхождения PUA в 397 док.**, 55 кодпоинтов.
- **НОРМАЛИЗОВАНО: 35 395 (95.73%)**, 47 кодпоинтов — по таблице Adobe Symbol.
- **НЕПОКРЫТО (needs_review, оставлено, НЕ дропнуто): 1 579 (4.27%)**, 8 кодпоинтов.

## Аудит (airtight)
char-by-char по КАЖДОМУ доку: всякое отличие old→new = покрытая-PUA → её Symbol-символ;
не-PUA позиции не тронуты. Остаток покрытых PUA после применения = **0**. Провенанс:
`latin_recovery.corrections`, `source=pua_normalize` (auto для покрытых, needs_review для нет).

## Контроль I1
Здоровые I1-доки СОДЕРЖАТ PUA (маркеры списков): 802=80, 845=97, 901=224, 1000=36, 66=133,
876=220 (+10 непокрытых). Не байт-в-байт (у них есть PUA), НО аудит доказал: изменились ТОЛЬКО
PUA-позиции, не-PUA контент байт-в-байт цел. Латиница на них — 0 замен (Group B цел).

## Топ нормализованных (Adobe Symbol, стандарт — не наивный младший байт)
| код | → | occ | | код | → | occ |
|---|---|---|---|---|---|---|
| U+F0B7 | `•` bullet | 30158 | | U+F062 | `β` | 109 |
| U+F02D | `−` minus | 3133 | | U+F061 | `α` | 97 |
| U+F0A7 | `♣` club* | 553 | | U+F0B4 | `×` multiply | 71 |
| U+F0A3 | `≤` | 249 | | U+F05D `]` / U+F05B `[` | 64/62 |
| U+F0D8 | `¬` not* | 237 | | U+F0B3 | `≥` | 56 |

`*` — `F0A7=♣`(club) и `F0D8=¬`(not) в ряде доков используются КАК МАРКЕРЫ СПИСКА (рядом с `•`).
Маппинг ВЕРЕН по таблице Adobe Symbol (глиф именно ♣/¬); если предпочтительнее заменить их на
`•`, это тривиальный доп-ремап. `F0B4`=× (multiply, 0xB4), а НЕ `F0D7` (dotmath ⋅, 0 вхождений в
корпусе — пользовательский пример F0D7→× опирался на наивный младший байт).

## Остаток непокрытых кодпоинтов (нужен per-font/human — по контексту)
Уже являются выходом ToUnicode = PUA (ToUnicode для них не даст лучше) → needs_review:
- **U+F07F** ×688 (4 док.) — чекбоксы анкеты (пустые квадраты рейтинга).
- **U+F0FC** ×418 (30 док.), **U+F0BE** ×98, **U+F0EA** ×15, **U+F0E9** ×4 — маркеры списков
  (расширители скобок/стрелок Symbol, используемые как буллеты) / стрелки ↑↓ лаб-значений
  (`↓MCV`) — ЗНАЧИМЫЕ, не дропаем.
- **U+F086** ×120, **U+E12C** ×229, **U+E46F** ×7 — маркеры списков кастомного шрифта (E-block).
