латинская/mixed-script порча в обучаемых зонах (sections/tables/excluded.appendices/metadata).

## Ключевые находки

1. **Порча ПОВСЕМЕСТНА и в основном КРИТИЧЕСКАЯ.** Доминируют кир-гомографы ВНУТРИ
   латинских медицинских кодов: `L04АA`/`L01АА` (ATC, Cyrillic А), `D08АС02`, `C10AС`,
   `N06AА`, `G20210А` (ген), `Г1-ГN` (TNM). Латиница `A/А C/С E/Е H/Н O/О` — идентичные
   глифы (класс C2), поэтому font-repair-контур их НЕ различает (см. 13 NO-GO); нужен
   E2 (eng-OCR) ИЛИ шаблон-сущности.
2. **Даже контрольная группа I1 (born-digital, PASS) несёт порченые коды** (КР901_1
   `D08АС02`, КР876_1 `C10AС/N06AА`). Значит «здоровый структурно» ≠ «здоровый текстово» —
   ровно дыра §4.3, которую закрывает 13b. Текущий пайплайн пропускает это (MIXED_SCRIPT —
   warning, не REVIEW).
3. **Детектор требует СЕГМЕНТНОГО разбора.** Наивный «cyr+lat в токене» дал 100% ложных
   (легит `T2-тип`, `HBsAg-положительный`). Флагаем только ВНУТРИ-СЕГМЕНТНОЕ смешение
   (сепараторы `-/.` режут на односкриптовые сегменты). Остаточный шум — токенизационные
   склейки (`ляторами(L`, `препараты(A04AD`), их доля мала.

## РЕШЕНИЕ по Р1 (самостоятельно): остаток ЗНАЧИТЕЛЕН → полный объём этапа

Остаток НЕ <5%, критических большинство (517 док.). Ветка «сократить до eng-OCR+гейт» —
неприменима. Порядок дальнейших шагов (Р2):
1. **ШАГ 3 — eng-OCR по кропу** (E2), в первую очередь по ЯЧЕЙКАМ таблиц (Р0: 438 455
   table-спанов слепы к гибрид-OCR по построению). Добавить `langs` в `ocr._clip_text`.
   Замерить, сколько снимает. Отдельный коммит.
2. Ветвление по Р2: снял >80% → LLM не нужна; <50% → LLM-ранкер по кропу (облако разрешено).
3. **Release-gate (ШАГ 8) — в любом случае:** документ с неразрешённым критическим латинским
   span'ом в обучаемой зоне → карантин.
4. **Разметка людьми — НЕ здесь (Р5):** агент готовит формат задач + конфиг Label Studio,
   саму разметку делает промпт 14. **После 13b — СТОП перед 14.**

**Замечание по FP:** для честных метрик детектор ещё ужесточить (снять токенизационные
склейки; отделить C3 I/1,O/0 от чистых confusables). Но ORDER остатка ясен: значителен,
критичен, доминируют confusable-коды — это НЕ задача, которую можно закрыть словарём.
