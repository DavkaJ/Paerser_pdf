## КАК ОТКРЫТЬ В LABEL STUDIO (одна команда, из корня проекта)

```
label-studio start latin_verify --init \
  --input-path _corpus/verify_queue/tasks_min.json \
  --label-config _corpus/verify_queue/labeling_config.xml \
  --input-format json-task
```
Затем http://localhost:8080. Каждая задача несёт ТРИ кропа (слово ≈600 DPI / строка / страница с
подсветкой bbox), исходный текст, предложенную замену и кандидатов. Кнопки разметчика: принять /
выбрать кандидата / ввести свой / «исходник верен» / «неразборчиво» / «нужен медэксперт» + тип
сущности. Экспорт решений → reviewed rules (промпт 14, тот же проект/формат).

## ФИКС Cowork-ревью 2 (ДО разметки) — третий класс тихой порчи закрыт

Cowork-ревью нашло: B3a/B3c авто-латинизировали ОДИНОЧНЫЕ русские предлоги, когда шаблон/сосед
несёт лат.букву в слоте. Аудит auto-набора: **88 таких** (41 B3a + 47 B3c). Материально:
КР1028_1 «а у 39%»→«MRSA 39%» (патоген, которого нет), КР942_1 «enterocolitica **у** детей»→«…**Y**
детей», класс «**с**»(with)→c (~30). Исправлено (`_RU_PREP`={с,у,а,и,в,к,о,я,б,ж}): предлог →
needs_review, не auto; GAP из одних предлогов («а у») отвергается; ЗАГЛАВНЫЕ генотипы
(Hepatitis В/С, Influenza А) сохранены. **Перегенерация → аудит: 88 → 0** (осталась 1 «ложная»
метка = легит `Hepatitis С у 1 ш з`→virus, где «у» — осколок с ш/з). Подтверждено: КР1028_1 MRSA
убран, КР942_1 Y убран, КР1_4 §2.3 цел (C×3, B×2). I1 байт-идентична. INVARIANTS I43,
`test_prep_protection.py`. **Разметку можно начинать — auto-набор больше не содержит порчи предлогов.**

## ARBITER — замер малой выборки (VLM `ai6-qwen3-vl-30b`, AND-гейт I28/I29)

Запуск `vlm_pilot.py 30 40` (30 контроль Group B + 40 выборка очереди), temperature=0,
structured output (закрытый список KEEP_ORIGINAL/CANDIDATE_A/CANDIDATE_B/ABSTAIN):

- **БЕЗОПАСНОСТЬ Group B: 0 / 30 ложных латинизаций русского → GO.** Арбитр на ВСЕХ 30 кропах
  подтверждённо-русских слов (pymorphy-known, из битых док., с соблазном eng-чтения) выбрал
  KEEP_ORIGINAL. Полный AND-гейт (нога языка `_source_is_russian` + независимый OCR + шаблон)
  не латинизировал ни одного. Русский защищён.
- **ЦЕННОСТЬ: 27.5% (11/40) выборки очереди AND-гейт перевёл бы в auto.** Примеры (все
  подтверждены и арбитром, и независимым OCR по токену): `ШСС→UICC`, `трепонема→pallidum`,
  `→Bacteroides`, `→RIPASA`, `→RUSSCO`, `→gonorrhoeae`, `→Grossman`, `→NEC`. Остальные 29 — в
  очередь (арбитр ABSTAIN/KEEP или OCR не подтвердил) — подсказка человеку, замена НЕ применяется.

**Вывод:** арбитр под AND-гейтом мог бы сократить ОСНОВНУЮ очередь ещё на ~27% БЕЗ риска Group B.
НЕ применено в этой сессии осознанно: (1) план — «маленькая выборка» (замер, не масс-прогон);
(2) «VLM НИКОГДА не молчаливый авторитет» — применение к ~3465 терминам = 3465 VLM-вызовов +
перегенерация, решение следующей сессии; (3) all-caps авто (ШСС→UICC) арбитр помечает на доп.
проверку человеком (c5_ambiguous). «Ноль авто арбитром» тоже был бы валиден — но замер показал
реальную ценность при нулевом риске.
